SurgeGuard 1.0

A real-time crowd-safety platform. It turns ordinary camera feeds into an explainable Crowd Stability Index and tells control-room operators what is happening, why, and what to do about it.

What it does

Every camera feed goes through Ultralytics YOLO (people only) and ByteTrack, so each person keeps an identity between frames. It runs on CUDA with FP16 when it can and falls back to the CPU, and it says which one it is using.

The score is CSI = clamp(100 − Σ wᵢ·pᵢ, 0, 100) over the five weighted indicators above. Weights renormalise when an indicator can't be measured, the score is smoothed, and a band change needs hysteresis before it takes effect. Every reading carries a confidence and the factor that limits it.

An evidence engine turns measurements into plain observations, such as "Opposing movement detected", each citing the number behind it. A decision engine then issues an operational report with actions like opening more exit capacity, which operators acknowledge and log to a timeline. It also forecasts queues, combines several cameras into one site view, and can drive an Arduino alert light and buzzer.

Multi-Mode AI Translator

Translate between languages with the Gemini API, or encode and decode Morse code. Speak your input, and hear the result read back.

view code
  • Python
  • Flask
  • Gemini API
  • Web Speech API
  • Tailwind CSS
What it does

Language mode sends text to the Gemini API and covers languages including Tamil, Telugu and Spanish. Morse mode encodes English, and decodes from typed text, a tap pad, or an uploaded .txt file.

Voice input uses the Web Speech API, translations can be read aloud, and a history log keeps past translations. The Morse player above is a small re-creation of the encoder for this page.
