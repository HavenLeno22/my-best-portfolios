Work

Four small instruments, all running live on this page. Each one began as a question I wanted to answer with a working prototype instead of a mockup. Open the notes on any module to see how it is built.

plotter

Seeded flow-field drawings, drawn line by line the way a pen plotter would.

lines
flow
seed 0000
How it's built

A flow field is a grid of angles taken from gradient noise. Every line starts at a random point and follows those angles until it leaves the paper. The random numbers come from a seeded generator, so the same seed always gives the same drawing.

It renders to canvas while you watch. Copying exports the same line data as clean SVG paths, ready to paste into Figma or send to a real plotter.

Canvas 2D, seeded PRNG, Perlin-style gradient noise

How it's built

A variable font stores a whole family in one file, with axes you can set to any value in between. This tester moves Archivo along its weight and width axes, the same font and axes used for every heading on this page. Click the sample to type your own text.

CSS font-weight and font-stretch on a variable font, container query units

life

Conway's Game of Life on a 16 by 16 LED matrix, stepped by the beat.

gen 0000
How it's built

The grid wraps at the edges, so a glider that leaves on the right comes back on the left. Draw cells with the pointer, or focus the grid and use the arrow keys and space.

When the drum machine is playing, the grid advances one generation on every beat instead of running on its own timer, so rhythm and pattern stay locked together.

Canvas 2D, typed arrays, the sequencer's audio clock

contrast

A contrast meter for text colours, with a fix that keeps the hue you chose.

Can you read this?

Body text needs a contrast ratio of at least 4.5 to 1 against its background. Large text can get by with 3 to 1.

How it's built

The ratio uses the WCAG 2 formula: the relative luminance of the lighter colour plus 0.05, divided by the darker one plus 0.05. Fix runs a binary search for the smallest lightness change to the text colour that reaches 4.5 to 1, so the hue you picked survives.

sRGB relative luminance, binary search, no colour libraries

About

I'm Leno, a designer who writes the code for what I design. Most of my work sits where interface design meets engineering: design systems, interactive tools, and the small details that make software feel considered.

I learned by taking apart websites I liked to see how they worked, and I still learn best that way. This page is hand-written HTML, CSS and JavaScript with no frameworks. I set that constraint to keep it fast, and to prove to myself I understand every part of it.

Away from the browser I listen to a lot of music with too many synthesizers in it, which explains the drum machine at the top of the page.

Process

Every project runs through the same signal chain. The order matters, and so does looping back to the start when something sounds wrong.

  1. 1

    listen

    Talk to the people who will use the thing and read what already exists. I write the problem down in one sentence before designing anything.

  2. 2

    sketch

    Prototype in the browser early, with real content. A rough version you can click beats a polished picture you can't.

  3. 3

    build

    Production code that is typed, accessible, and quick on a cheap phone. Design decisions become tokens and components, not one-off styles.

  4. 4

    tune

    Ship it, watch how it gets used, and adjust. Most of the quality in a product comes from the second and third pass.
