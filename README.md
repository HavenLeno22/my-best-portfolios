# My Best Portfolios

A collection of portfolio sites. Each one lives in its own folder, is a complete static site, and
runs without a build step or dependencies.

| | Portfolio | Idea |
| --- | --- | --- |
| 1 | [Leno Instrument No. 1](portfolio-1/) | The portfolio is a piece of hardware: a playable Web Audio drum machine, a rack of four working tools, and a patch cable you plug in to get in touch. |

## Run one

Double-click its `index.html`, or start the local server that ships with it:

```bash
python portfolio-1/serve.py
```

Then open http://127.0.0.1:5173. Each portfolio's own README covers how to personalise and publish it.
