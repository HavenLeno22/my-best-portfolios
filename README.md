# My Best Portfolios

Portfolio sites by **Haven Leno J**, full-stack developer. Each one lives in its own folder, is a
complete static site, and runs without a build step or dependencies.

**Live:** https://havenleno22.github.io/my-best-portfolios/

| | Portfolio | Idea |
| --- | --- | --- |
| 1 | [Instrument No. 1](portfolio-1/) ([live](https://havenleno22.github.io/my-best-portfolios/portfolio-1/)) | The portfolio is a piece of hardware: a playable Web Audio drum machine, a rack of four projects, and a patch cable you plug in to get in touch. |

## Run one locally

Double-click its `index.html`, or start the local server that ships with it:

```bash
python portfolio-1/serve.py
```

Then open http://127.0.0.1:5173. Each portfolio's own README covers how to change and publish it.

## Adding a portfolio

Create `portfolio-2/` with its own `index.html`, then add a row to the table above and a card to
the root `index.html`. GitHub Pages publishes it on the next push.
